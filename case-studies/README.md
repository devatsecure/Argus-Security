# Case studies and illustrative examples

The two case studies currently in this directory are **fictional examples**.
Their organizations, testimonials, outcomes, and financial figures illustrate
possible scenarios; they are not verified customers, deployments, or measured
Argus adoption results.

For public integration evidence and its limitations, see [ADOPTERS.md](../ADOPTERS.md).

## Fictional examples

| Example | Illustrative scenario |
| --- | --- |
| [PayFlow Technologies](example-fintech-startup.md) | A fictional payment-processing startup incorporating security reviews into development. |
| [AsyncDB Project](example-open-source.md) | A fictional open-source database project incorporating automated reviews. |

Do not aggregate the examples' metrics into project-wide performance claims or
count their fictional organizations as adopters. No verified customer case study
is listed in this directory as of 2026-10-07.

## Submit a real case study

Use the [case-study template](template.md) and submit a pull request containing:

1. The real project or organization, with permission to publish its name and story.
2. Its Argus workflow or deployment configuration and the versions used.
3. Evidence of execution, such as public workflow runs or shareable reports.
4. Results with their measurement period, baseline, method, and limitations.
5. A clear label for any estimates, anonymized details, or hypothetical examples.

Verified stories can be listed separately from these fictional examples and
linked from [ADOPTERS.md](../ADOPTERS.md) when public integration evidence is available.

For setup instructions, see the [quick-start guide](../docs/QUICKSTART.md).
